      帮助

      TdxClaw AI 写作助手 · 网页版
      面向长篇小说的写作工具。装不下的上下文先省再压，AI 失败绝不写回正文， 章节梗概成链、设定集当事实基准。
      做得最多的事：把一个想法写成几十万字还不崩结构。

      这一版是人机共用工作区：你在网页上写，agent 通过 MCP 也能读写同一本书， 两边看到的是同一份稿子、同一套设定与外观配置（都在服务器上）。

      仓库：

      桌面壳层的东西这里都换了形式：AI 面板能点「浮动」拖成浮层（对应独立浮窗）、 关页面时若有没存上的字会拦一下（对应退出确认）。仍然没有的是「首启欢迎」 和「路径设置」——网页版的稿子都在服务器上，没有「本机路径」这个概念。 自动保存改成停手 1.2 秒即存（桌面是 60 秒 + 失焦），比桌面更勤。

      Ctrl+S立即保存（平时停手 1.2 秒自动存）
      Ctrl+F查找替换（可切全书范围）
      Ctrl+EnterAI 生成
      Enter / Shift+Enter查找框里：下一个 / 上一个

      编辑框内的撤销、重做、剪切、复制、粘贴沿用浏览器自身的快捷键。

      这里列出的是把编辑器接进 agent 客户端（Codex / Claude / Cursor…）的配置。 接上之后，你在 agent 里说一句「打开某某书稿，给第 3 章续写 800 字」， 它就能直接读写你的稿子；网页此时会实时跟着切章、同步设定。

      给另一台设备用：下载后在那台设备上运行，输入账号密码即可—— 它自己会找到 Claude / Cursor / Codex / WorkBuddy 等客户端并写好配置（改前自动备份）。
